# Benchmark: Classical ML vs. 1D-CNN vs. 2D-CWT-CNN (unified, audited)

All numbers are generated by `model_training/deep_learning/unified_benchmark.py`. **Within each task the three model families use exactly the same train/test indices.** CNNs are trained for a fixed number of epochs and the *last-epoch* model is evaluated (no epoch/threshold selection on the evaluation data). `mean ± std` = over 3 CNN seeds (noise, plant) or over 3 repeated grouped-CV split seeds (stress).

## 1. Noise vs. Cavitation

**Common basis (replicates the classical hold-out of `train_and_save_noise_model.py`):** 24,273 labelled recordings -> stratified 80/20 split (`random_state=42`, *not* grouped) -> 19,418 train recordings; the noise class of the train part is down-sampled 5:1 -> **6,636 training samples** (1106 signal / 5,530 noise). The hold-out test set is the untouched 20 % of the whole database: **4,855 events** (277 cavitation / 4,578 noise, natural 5.7 % prevalence).

Why 4,855 and not ~1,330: the 20 % split is taken from the full database (24,273 recordings) *before* balancing; 6,648 (6,636 today) is the already down-sampled training subset, not the pool. 277 signal events = 20 % of all ~1,383 cavitation events (not 25 % of the 1,108 training candidates).

Notes:

- The thesis value **0.9961 is a *weighted* F1** (`average='weighted'` in the training script), not Macro F1. Macro F1 of the same RF is lower because signal precision is only ~93 % (19 false alarms among 4,578 noise events).

- **Leakage caveat:** this hold-out split is random, not grouped. 44 of 50 test experiments also occur in the training data, so all three models (identically) may profit from session similarity. Noise detection should therefore be read as an upper bound for unseen sessions.
- Because the test set is 94 % noise, accuracy is dominated by noise; use signal recall / F2 and Macro F1.

## 2. Plant species (Leave-One-Plant-Out)

**Common basis:** the *exact* LOPO folds of `train_and_save_plant_model.py` were reproduced (same RNG sequence; verified: per-plant test counts and class supports are identical to `plant_model_metadata.json`). 13 plants with >= 5 events are held out once. In each fold, training events are capped at 150 per species. Because Tomato has only 140 total cavitation events in the database, the nominal class-capped training pool is **150 + 150 + 140 = 440 samples** (as reported in Table 6.1). When holding out plants with large event counts (e.g., Plant 42 with 949 pepper events leaves only 45 pepper events in training; Plant 20 with 84 tomato events leaves only 56 tomato events), the actual training count per fold ranges from **335 to 440 events** (average: 419 events). Test events per plant are capped at 150 -> **575 pooled test events** {'Mini Pepper': 195, 'Sunflower': 248, 'Tomato': 132}. Majority-class baseline = 43.1%.

This confirms that specimen acoustic resonance and sensor coupling overshadow botanical species differences.

## 3. Stress type (cut vs. drought)

**Common basis:** grouped 5-fold cross-validation (`StratifiedGroupKFold`, groups = `plant_id`), so no plant appears in train and test of the same fold. Classical models and CNNs get identical folds; the whole CV is repeated with 3 split seeds (42, 43, 44). Classical features: 62 (log1p on duration/counts/spec_high_freq_energy_ratio, median imputation, robust scaling; SVM RBF C=1, class_weight=balanced; RF 200 trees, depth 8). Both datasets are exactly balanced, therefore **pooled accuracy = pooled balanced accuracy** (the previous report averaged per-fold balanced accuracies, which is degenerate here because several folds contain plants of only one class - that column was removed). Chance level = 50 %.
